## ?? ????? Pointing Model

### Model Equation:
```
?Az  = IH + NP·tan(Alt) + CH·sec(Alt) + MA·cos(Az)·tan(Alt) + 
       ME·sin(Az)·tan(Alt) + HCES·sin(Az) + HCEC·cos(Az) + 
       TF·cos(Alt) + TX·sin(Alt)

?Alt = ID + CV + (other altitude terms...)
```

### Least-Squares Solution:
```
[A]·[x] = [b]

Where:
  A = Design matrix (40 × 11)  ? ??? calibration geometry
  x = Model terms (11 × 1)      ? ?????????
  b = Error vector (40 × 1)     ? ??? plate solving

Solution:
  x = (A^T·A)^-1·A^T·b          ? QR decomposition
```
