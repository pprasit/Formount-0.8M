### For Developers:

**Access Corrected Positions:**
```csharp
// Get corrected position (use this for display/tracking)
double azCorrect = mountInfo.Act_Azimuth_Pos_Correct;
double altCorrect = mountInfo.Act_Altitude_Pos_Correct;

// Get raw position (for debugging only)
double azRaw = mountInfo.Act_Azimuth_Pos_Raw;
double altRaw = mountInfo.Act_Altitude_Pos_Raw;

// Get correction magnitude
double azError = azRaw - azCorrect;
double altError = altRaw - altCorrect;
Console.WriteLine($"Model corrects: {azError:F3}° in Az, {altError:F3}° in Alt");
```

**Check Model Status:**
```csharp
var pm = pollingManager.PointingModelManager;

if (pm.IsModelLoaded)
{
    Console.WriteLine("? Pointing model active");
    var info = pm.GetModelInfo();
    Console.WriteLine($"Residual RMS: {info.ResidualRMS:F3} arcsec");
}
else
{
    Console.WriteLine("No model loaded (using raw positions)");
}
```

## ?? Model Terms Explained

| Term | Name | Physical Meaning | Typical Value |
|------|------|------------------|---------------|
| IH | Azimuth Index Error | Zero point offset (azimuth) | 0.1-5° |
| ID | Altitude Index Error | Zero point offset (altitude) | 0.1-5° |
| NP | Non-Perpendicularity | Axes not 90° apart | 0.01-0.5° |
| CH | Horizontal Collimation | Optical axis offset (horizontal) | 0.001-0.1° |
| CV | Vertical Collimation | Optical axis offset (vertical) | 0.001-0.1° |
| MA | Azimuth Axis Misalignment | Az axis not vertical | 0.01-0.5° |
| ME | Altitude Axis Misalignment | Alt axis not horizontal | 0.01-0.5° |
| HCES | Azimuth Encoder Sin Error | Periodic encoder error (sin) | 0.0001-0.01 |
| HCEC | Azimuth Encoder Cos Error | Periodic encoder error (cos) | 0.0001-0.01 |
| TF | Tube Flexure | Tube bends (cos component) | 0.001-0.1° |
| TX | Tube Flexure Tilt | Tube bends (sin component) | 0.001-0.1° |

## ?? Troubleshooting

### Model Not Loading?
```
Check: Does PointingModel.pmd exist?
Location: {AppDir}\PointingModel.pmd

View Debug Output:
[PointingModelManager] Attempting to load model...
[PointingModelManager] ? Model loaded successfully  ? Should see this
```

### No Improvement?
```
Check model terms are reasonable:
- |IH| < 10° (if larger, something is wrong)
- |MA| < 1° (if larger, mount seriously misaligned)

View correction magnitude:
double error = mountInfo.Act_Azimuth_Pos_Raw - mountInfo.Act_Azimuth_Pos_Correct;
// Should be ~1-5° typically
// If 0° ? model not being applied
// If >10° ? model is wrong
```

### Calibration Failed?
```
Need at least 10 solved points for reliable model
Check plate solving settings:
- Exposure time sufficient? (3-10 seconds)
- Focus good?
- Stars visible?

View calibration dialog:
Solved: 37/40 ? (good)
Solved: 5/40 ? (insufficient)
```
