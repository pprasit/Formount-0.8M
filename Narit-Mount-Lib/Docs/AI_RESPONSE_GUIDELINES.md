## ?? **Key Principles:**

1. **Be Concise** - User wants action, not explanation
2. **Use Bullets** - Easy to scan
3. **Use Tables** - Clear status overview
4. **Call Tools Immediately** - Don't ask permission
5. **Short Summary** - Just facts, no fluff
