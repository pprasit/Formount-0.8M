## ?? Usage Example

### ????? Polling Cycle (50ms):

```csharp
// 1. Read encoder positions
double azCounts = azimuthInfo.Raw_Position;
double altCounts = altitudeInfo.Raw_Position;

// 2. Convert to degrees
double azRaw = (azCounts / azEncoderRes) * 360.0 + azOffset;
double altRaw = (altCounts / altEncoderRes) * 360.0 + altOffset;

// 3. Update MountInfo with RAW positions
mountInfo.UpdateRawPosition(azRaw, altRaw);

// 4. Apply pointing model correction (if loaded)
if (pointingModel != null)
{
    double azError = pointingModel.CalculateAzimuthError(azRaw, altRaw);
    double altError = pointingModel.CalculateAltitudeError(azRaw, altRaw);
    
    mountInfo.ApplyPointingModelCorrection(azError, altError);
}

// 5. Now use corrected positions for display/calculations
double displayAz = mountInfo.Act_Azimuth_Pos_Correct;   // ? Use this
double displayAlt = mountInfo.Act_Altitude_Pos_Correct; // ? Use this
```
