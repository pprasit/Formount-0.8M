NARIT Mount API — User Guide

Complete reference for controlling the NARIT Fork Mount telescope via the NaritMountController C# API. Covers connection, motion, pointing model persistence, offsets, sidereal/satellite/small-body tracking, status polling, and event subscriptions.

Overview

The NARIT Mount API (NARIT.Mount.API) is a .NET 10 class library that provides a clean, high-level interface for controlling the NARIT fork-mounted telescope at the Thai National Observatory (Doi Inthanon, 2457 m).

Key capabilities:

  • Dual-axis control — coordinated Azimuth + Altitude commands
  • Manual jogging — single-command dual-axis jog workflow for operator control
  • Telescope offset workflow — offset type, step size, direction, and reset support
  • Sidereal tracking — PIDF controller at 66 Hz with Kalman filtering
  • Satellite tracking — TLE / SGP4 propagation
  • Asteroid / comet tracking — user-supplied orbital elements for small-body targets
  • Pointing model — automatic encoder-to-sky correction
  • Persistent settings — pointing model path is restored from AppSetting.json
  • NTP time sync — sub-millisecond time accuracy
  • Real-time events — position updates, tracking state, errors

Quick Start

using NARIT.Mount.API;
using NARIT.Mount.API.Models;

// 1. Create controller
using var mount = new NaritMountController();

// 2. Configure observer site (required for tracking)
mount.SetObserverSite(ObserverSite.NARIT_DoiInthanon);

// 3. Connect to hardware
bool ok = await mount.ConnectAsync();
if (!ok) return;

// 4. Enable drives
mount.Enable();

// 5. Track Betelgeuse (RA 5.9195h, Dec +7.4072 deg)
mount.TrackObject(5.9195, 7.4072, "Betelgeuse");

// 6. Monitor tracking
var info = mount.GetTrackingInfo();
Console.WriteLine($"On target: {info.IsOnTarget}  RMS Az: {info.AzimuthRms_Arcsec:F1}\"");

// 7. Stop and cleanup
mount.StopTracking();
mount.Disable();
mount.Disconnect();

Installation

  1. Add a project reference to NARIT-Mount-API.csproj in your solution.
  2. The API targets .NET 10 (Windows) — your project must also target net10.0-windows.
  3. Ensure the Elmo Platinum Drive hardware (or simulator) is accessible via COM port.

Connection

ConnectAsync() async

Scans for available Platinum Drive hardware and connects to the first one found. Creates internal polling manager, tracking engines, and pointing model.

bool success = await mount.ConnectAsync();
if (!success)
{
    Console.WriteLine("Connection failed!");
}
ReturnsTask<bool> — true if connected successfully
ThrowsObjectDisposedException if the controller has been disposed

Disconnect() void

Stops tracking, stops polling, disconnects from drive hardware.

mount.Disconnect();

IsConnected

Read-only property. true when connected to drive hardware.

Configuration

SetObserverSite(site) void

Sets the observer location for RA/Dec to Az/Alt coordinate conversion. Required before tracking.

// Option 1: Use preset
mount.SetObserverSite(ObserverSite.NARIT_DoiInthanon);

// Option 2: Custom location
mount.SetObserverSite(new ObserverSite(
    latitude:  18.5736,   // degrees North
    longitude: 98.4820,   // degrees East
    elevation: 2457,      // meters
    timezoneUtcOffset: 7  // UTC+7
));

SetPointingModelPath(filePath) void

Loads a PointXP pointing model file (.pxp or .pmd) that corrects mechanical/alignment errors.

mount.SetPointingModelPath(@"C:\Models\MyMount.pxp");
Note Can be called before or after ConnectAsync(). The selected path is now saved to AppSetting.json and restored automatically on the next startup.

SetNtpConfig(config) void

Configures NTP time synchronization for accurate timestamp and sidereal time calculations.

// Use Thai NTP server
mount.SetNtpConfig(NtpConfig.ThaiNtp);

// Or custom
mount.SetNtpConfig(new NtpConfig("pool.ntp.org", syncIntervalSeconds: 1800));

GetObserverSite()

Returns the current ObserverSite or null if not set.

Drive Control

Enable() void

Enables both axis motors simultaneously. Drives must be enabled before any motion command.

mount.Enable();

Disable() void

Disables both axis motors. Automatically stops any active tracking first.

mount.Disable();

IsMountEnabled

Read-only property. true when both drives are enabled. Reads directly from the hardware polling data (AzimuthInfo.Is_Drive_Enabled && AltitudeInfo.Is_Drive_Enabled) for immediate accuracy.

Motion Commands

GotoPosition(az, alt, velocity) void

Slews both axes to the specified position at the given velocity. Automatically stops any active tracking.

mount.GotoPosition(
    azimuthDeg: 180.0,
    altitudeDeg: 45.0,
    velocityDegPerSec: 5.0
);
ParameterTypeDescription
azimuthDegdoubleTarget azimuth in degrees
altitudeDegdoubleTarget altitude in degrees
velocityDegPerSecdoubleSlew speed in degrees/second

MoveVelocity(azVel, altVel) void

Commands both axes to move at continuous velocities until stopped. Stops tracking first.

mount.MoveVelocity(
    azVelocityDegPerSec: 1.0,
    altVelocityDegPerSec: 0.5
);

Jog(azVel, altVel) void

Jog both axes at specified velocities. Semantically identical to MoveVelocity but intended for manual/interactive control. The API stops active tracking before starting a manual jog command.

mount.Jog(0.5, 0.0);  // Jog azimuth at 0.5 deg/s

ApplyOffset(offsetType, stepSizeArcsec, direction) void

Applies a telescope offset using the same operator flow as the Camera / Offset panel in the main application.

mount.ApplyOffset(
    offsetType: OffsetType.RaDec,
    stepSizeArcsec: 10,
    direction: OffsetDirection.NE
);
ParameterTypeDescription
offsetTypeOffsetTypeCoordinate mode: RaDec or AltAzm
stepSizeArcsecdoubleOffset step size in arcseconds
directionOffsetDirectionOne of N, S, E, W, NE, NW, SE, SW

ResetOffset() void

Clears the accumulated telescope offset on both axes.

mount.ResetOffset();

Stop() void

Emergency stop — halts all motion on both axes and stops tracking.

mount.Stop();

Tracking

TrackObject(ra, dec, name) void

Track a celestial object by J2000 RA/Dec coordinates. The engine automatically handles precession, coordinate conversion, and PIDF control at 66 Hz.

// Track Betelgeuse
mount.TrackObject(
    raHours: 5.9195,       // RA in hours (0-24)
    decDeg:  7.4072,       // Dec in degrees (-90 to +90)
    objectName: "Betelgeuse"
);
ParameterTypeDescription
raHoursdoubleRight Ascension in hours (0–24)
decDegdoubleDeclination in degrees (−90 to +90)
objectNamestringOptional display name
Prerequisite You must call SetObserverSite() before using any tracking method.

TrackSidereal() void

Start sidereal tracking at the current mount position. Converts the current Az/Alt to RA/Dec and tracks it.

mount.TrackSidereal();

TrackSatellite(tle1, tle2, name) void

Track a satellite using Two-Line Element (TLE) data with SGP4 propagation.

string tle1 = "1 25544U 98067A   24001.50000000  .00016717  00000-0  10270-3 0  9002";
string tle2 = "2 25544  51.6400 208.9163 0006703  30.1579 330.0197 15.49560532999999";

mount.TrackSatellite(tle1, tle2, "ISS (ZARYA)");

TrackAsteroid(elements) void

Tracks an asteroid using user-supplied orbital elements.

mount.TrackAsteroid(new AsteroidOrbitalElements
{
    Name = "Ceres",
    Epoch_JD = 2460400.5,
    SemiMajorAxis_AU = 2.7675,
    Eccentricity = 0.0758,
    Inclination_Deg = 10.593,
    LongAscendingNode_Deg = 80.305,
    ArgPerihelion_Deg = 73.597,
    MeanAnomaly_Deg = 95.989
});

TrackComet(elements) void

Tracks a comet using user-supplied orbital elements. The current implementation supports elliptical comet orbits.

mount.TrackComet(new CometOrbitalElements
{
    Name = "67P/Churyumov-Gerasimenko",
    PerihelionEpoch_JD = 2460673.5,
    PerihelionDistance_AU = 1.2432,
    Eccentricity = 0.6405,
    Inclination_Deg = 7.040,
    LongAscendingNode_Deg = 50.181,
    ArgPerihelion_Deg = 12.780
});

TrackNearEarthObject(elements) planned

Track a Near-Earth Object using Keplerian orbital elements.

Not Yet Implemented This method currently throws NotImplementedException. It requires an ephemeris propagator to be added to the engine.

StopTracking() void

Stops all tracking and halts both axes.

mount.StopTracking();

GetTrackingInfo() model

Returns a TrackingInfo snapshot of the current tracking session.

var info = mount.GetTrackingInfo();
Console.WriteLine($"Mode: {info.Mode}");
Console.WriteLine($"Target: RA={info.TargetRA_Hours:F4}h Dec={info.TargetDec_Deg:F4} deg");
Console.WriteLine($"On target: {info.IsOnTarget}");
Console.WriteLine($"RMS: Az={info.AzimuthRms_Arcsec:F1}\" Alt={info.AltitudeRms_Arcsec:F1}\"");
Console.WriteLine($"Duration: {info.Duration}");

IsTracking

Read-only property. true when sidereal or satellite tracking is active.

Status & Position

GetStatus() model

Returns a comprehensive MountStatus snapshot.

var status = mount.GetStatus();
Console.WriteLine($"State: {status.State}");
Console.WriteLine($"Enabled: {status.IsMountEnabled}");
Console.WriteLine($"Tracking: {status.IsTracking} ({status.CurrentTrackingMode})");
Console.WriteLine($"NTP synced: {status.IsTimeSynchronized} (offset {status.NtpOffsetMs:F1}ms)");
Axis telemetry MountStatus now includes per-axis Axis_Status values (Disabled, Idle, Slewing, Tracking) and RMS values that automatically return 0 when the axis is not actively tracking or slewing.

GetPosition() model

Returns a MountPosition snapshot with raw and corrected positions.

var pos = mount.GetPosition();
Console.WriteLine($"Az Raw: {pos.Azimuth_Raw_Deg:F4} deg  Corrected: {pos.Azimuth_Corrected_Deg:F4} deg");
Console.WriteLine($"Alt Raw: {pos.Altitude_Raw_Deg:F4} deg  Corrected: {pos.Altitude_Corrected_Deg:F4} deg");

Per-Axis Control (IAxisController)

Access individual axis controllers via mount.AzimuthAxis and mount.AltitudeAxis for independent control.

Event System

PositionChanged event

Raised at the polling rate (~66 Hz) with the latest position data.

mount.PositionChanged += (sender, e) =>
{
    Console.WriteLine($"Az: {e.Position.Azimuth_Corrected_Deg:F4} deg  " +
                      $"Alt: {e.Position.Altitude_Corrected_Deg:F4} deg");
};

TrackingStateChanged event

Raised when tracking starts, stops, or changes mode.

mount.TrackingStateChanged += (sender, e) =>
{
    Console.WriteLine($"Tracking: {e.IsTracking}  Mode: {e.Mode}  Object: {e.ObjectName}");
};

ErrorOccurred event

Raised when a mount error occurs.

mount.ErrorOccurred += (sender, e) =>
{
    Console.WriteLine($"ERROR: {e.Message} (recoverable: {e.IsRecoverable})");
    if (e.Exception != null)
        Console.WriteLine($"  Exception: {e.Exception}");
};

Full Example

using NARIT.Mount.API;
using NARIT.Mount.API.Models;

class Program
{
    static async Task Main()
    {
        using var mount = new NaritMountController();

        // Subscribe to events
        mount.PositionChanged += (s, e) =>
        {
            // Called ~66Hz — update UI or log
        };

        mount.TrackingStateChanged += (s, e) =>
        {
            Console.WriteLine($"[TRACKING] {e.Mode} — {e.ObjectName} (active: {e.IsTracking})");
        };

        mount.ErrorOccurred += (s, e) =>
        {
            Console.WriteLine($"[ERROR] {e.Message}");
        };

        // Configure
        mount.SetObserverSite(ObserverSite.NARIT_DoiInthanon);
        mount.SetNtpConfig(NtpConfig.ThaiNtp);
        mount.SetPointingModelPath(@"C:\Models\ForkMount.pxp");

        // Connect
        if (!await mount.ConnectAsync())
        {
            Console.WriteLine("Failed to connect!");
            return;
        }

        Console.WriteLine("Connected! Enabling drives...");
        mount.Enable();

        // Slew to park position
        Console.WriteLine("Slewing to park...");
        mount.GotoPosition(0, 90, 5.0);
        await Task.Delay(10000);

        // Track Betelgeuse
        Console.WriteLine("Tracking Betelgeuse...");
        mount.TrackObject(5.9195, 7.4072, "Betelgeuse");

        // Monitor for 60 seconds
        for (int i = 0; i < 60; i++)
        {
            await Task.Delay(1000);
            var info = mount.GetTrackingInfo();
            var pos  = mount.GetPosition();

            Console.WriteLine(
                $"[{i + 1}s] On target: {info.IsOnTarget}  " +
                $"RMS: Az={info.AzimuthRms_Arcsec:F1}\" Alt={info.AltitudeRms_Arcsec:F1}\"  " +
                $"Az={pos.Azimuth_Corrected_Deg:F4} deg  Alt={pos.Altitude_Corrected_Deg:F4} deg");
        }

        // Cleanup
        mount.StopTracking();
        mount.Disable();
        mount.Disconnect();

        Console.WriteLine("Done!");
    }
}

Error Handling

The API throws standard .NET exceptions:

ExceptionWhen
InvalidOperationExceptionMethod called when not connected
InvalidOperationExceptionTracking method called without observer site
ObjectDisposedExceptionMethod called after Dispose()
ArgumentOutOfRangeExceptionRA not in 0–24 or Dec not in ±90
ArgumentNullExceptionRequired parameter is null
FileNotFoundExceptionPointing model file not found
NotImplementedExceptionTrackNearEarthObject() (planned feature)
ErrorOccurred Event Non-throwing errors (e.g., hardware communication issues) are reported via the ErrorOccurred event instead of exceptions.

Lifecycle & Dispose

NaritMountController implements IDisposable. Always dispose when done:

// Option 1: using statement (recommended)
using var mount = new NaritMountController();

// Option 2: manual dispose
var mount = new NaritMountController();
try
{
    // ... use mount ...
}
finally
{
    mount.Dispose();
}

The recommended lifecycle order:

  1. new NaritMountController()
  2. SetObserverSite()
  3. SetPointingModelPath() (optional)
  4. SetNtpConfig() (optional)
  5. await ConnectAsync()
  6. Enable()
  7. Motion / Tracking commands
  8. StopTracking()
  9. Disable()
  10. Disconnect()
  11. Dispose()

Release Updates & Notes (v1.2)

New: Operator Control Expansion

  • Dual-axis Jog now behaves as a single mount-level command intended for operator control.
  • Offset commands are available through ApplyOffset() and ResetOffset().
  • Pointing model path is persisted and restored automatically from AppSetting.json.
  • Asteroid and comet tracking are now available from orbital elements supplied by the caller.
  • Axis status reporting exposes Disabled, Idle, Slewing, and Tracking at the API surface.

Fix: Enable/Disable Status Not Updating

Problem After calling mount.Enable() or mount.Disable(), the IsMountEnabled property and GetStatus().State did not reflect the actual drive state. The status remained stuck on Disabled.

Root Cause

The internal MountManager (which calculates IsMountEnabled at 200 Hz) reads drive status from the global App.PollingManager singleton. However, ConnectAsync() created a new CentralizedPollingManager without registering it with App.PollingManager, so MountManager was reading null — the enable status was never propagated.

Fix Applied

  • ConnectAsync() now sets App.PollingManager = _pollingManager after creation, ensuring all internal managers read from the correct data source.
  • Disconnect() now clears App.PollingManager to prevent stale references.
  • IsMountEnabled now reads directly from AzimuthInfo.Is_Drive_Enabled && AltitudeInfo.Is_Drive_Enabled instead of relying on the asynchronous MountManager update cycle, making it immediately accurate.

Fix: TrackObject Spinning Forever

Problem Calling mount.TrackObject(ra, dec, name) caused the mount to spin at maximum velocity indefinitely instead of converging on the target.

Root Cause

Same root cause as the Enable/Disable issue. The SiderealTracking PIDF controller reads the current mount position from MountInfo.Act_Azimuth_Pos_Correct / Act_Altitude_Pos_Correct, which are calculated by MountManager. Because App.PollingManager was null, corrected positions were never computed and remained at 0°. The PIDF controller saw an enormous error (target − 0°) and commanded maximum velocity continuously.

Fix Applied

Registering App.PollingManager in ConnectAsync() resolved this automatically. MountManager now correctly computes corrected positions, and the PIDF controller converges to the target as designed.

Fix: SatelliteTracking NullReferenceException

Problem During satellite tracking, calling StopTracking() occasionally caused a System.NullReferenceException crash inside the tracking computation loop (ComputeAndSendCommands).

Root Cause

A race condition between the 15 ms timer thread and the StopTracking() call on the UI thread. The tracking timer checks _satelliteTracker != null at the start of the method, but StopTracking() sets _satelliteTracker = null on another thread between the null-check and the subsequent use of the field (e.g., _satelliteTracker.GetTopocentric(...)), causing the crash.

Fix Applied

Both TrackingTimer_Elapsed() and ComputeAndSendCommands() now capture local snapshots of _satelliteTracker and _observerLocation at the very start of the method. The local references remain valid for the entire method execution regardless of whether StopTracking() nullifies the fields on another thread.

// Inside ComputeAndSendCommands():
var tracker = _satelliteTracker;    // local snapshot
var observer = _observerLocation;   // local snapshot

if (!_isTracking || tracker == null || observer == null)
    return;

// Safe to use tracker and observer throughout the method
var topoCurrent = tracker.GetTopocentric(observer, utcNow);  // no crash
var topoFuture  = tracker.GetTopocentric(observer, ...);     // no crash

Thread Safety Notes

Important The NaritMountController is designed for single-threaded use from the calling application. Internally, tracking engines run on background timer threads. When calling StopTracking() or Disconnect(), the API safely handles concurrent access to shared state. However, users should avoid calling multiple API methods simultaneously from different threads.
